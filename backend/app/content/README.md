# Contenu de référence produit (à peupler)

Ce dossier accueillera les documents de référence de Clea une fois fournis,
convertis en texte exploitable dans les prompts de classification
(`docs/CLAUDE.md` → "Ne jamais halluciner de critères typologiques").

À obtenir avant de sortir la morphologie du statut placeholder :

- [ ] Document types de silhouette corporelle (H / A / V / O / X) — critères distinctifs
- [ ] Document formes de visage (7 types) — **traits du visage par forme non résolus à date**
- [ ] Document formes des yeux (9+ types)
- [ ] Table de correspondance undertone + contraste + cheveux → saison colorielle (4 saisons / 12 sous-saisons)

Tant qu'un document n'est pas fourni, le code correspondant reste en
placeholder explicite (`NotImplementedError` ou texte "[EN ATTENTE...]")
plutôt que d'inventer des critères.
